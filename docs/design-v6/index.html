04 / HELD OUT

Then try it somewhere untouched.

Twenty held-out boards, seeds 100–119. Same boards for every player. A crash ends the game.

Echo alone looks like Jev.
Echo + search does not.

Echo + search averaged 38.8 food versus Jev's 7.5, while still using less wall-clock time per move: 103 ms versus 159 ms.

It won all 20 paired held-out boards. Twenty boards is still a small sample.
05 / WHAT BROKE

The experiment kept finding ways to lie.

The useful part of the project was not getting a good number. It was finding the reasons the number might be fake.

01

The first student had an easier job.

It consumed 28 features that code had already computed while Jev had to read the board. That was not a fair comparison, so Echo was rebuilt to read the raw board state.

02

Copying Jev's games was not enough.

One Echo mistake can send the game into a state Jev's own trajectories never visited. So Echo drove and Jev labelled wherever Echo ended up, then Echo retrained. Twice.

03

Search accidentally knew the future.

Cloning the game's random generator leaked where the next food would appear. The search simulator was changed to draw fresh random future food, and the result was rerun.

06 / BUILD

The copy can stay tiny because the job is tiny.

Echo is not a replacement for Jev. It is one narrow slice of Jev's behaviour, distilled into a 22,212-parameter convolutional network.

01

Label

Jev sees the raw Snake board and returns a move distribution.

02

Distill

03

Follow mistakes
