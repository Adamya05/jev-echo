Why build Echo?

800× faster

0.2 ms a move against ~160 ms, and Echo alone picks the same move as Jev 93% of the time.*

5× the score

With search, Echo looks about seven turns ahead at every move before it commits, and it's still no slower than Jev.

To play like Echo + search, Jev would need about 361 calls per move: roughly 6.1 hours and $2.76 a game.

What does Echo learn?

To predict what Jev would say about a board. Jev labelled 38,199 boards for $0.77, and Echo trained on them in about a minute on a laptop.

Train your own

  1. Have Jev label your inputs.
    14,391 boards cost $0.29.

    export SNAKE_ALLOW_CRASH=1
uv run python collect_raw.py --games 90 --out results/dataset_board_crash.npz

  2. Train Echo to copy it.
    About 30 seconds on a laptop.

    uv run python train_board.py --data results/dataset_board_crash.npz \
    --out results/student_board_crash.npz

  3. Let Echo drive. Have Jev label the boards Echo actually reaches, then retrain.
    Twice: 23,808 more boards for $0.48. The README has both rounds.

    uv run python collect_raw.py --driver echo --echo results/student_board_crash.npz \
    --games 250 --max-steps 2000 --seed-offset 5000 --out results/dataset_board_crash_dagger1.npz

  4. Race them.
    On boards none of the training touched.

    uv run python -m sysone.snake.compare --games 20 --seed-offset 100 --max-steps 2000 \
    --workers 1 --configs jev_raw board_student board_tree_181

Snake makes looking ahead cheap because the next board is exactly predictable. In other problems, the saved time will be better spent on something else.
