Echo learns to play like Jev.

It is trained to copy Jev, not to beat Snake. On held-out boards, Echo picks the same top move 93% of the time, mistakes and all.
The interesting part starts when that behaviour costs almost nothing.
01 / COPY

First, copy the instinct.

Jev sees a Snake board and returns a probability distribution over the available directions. Echo learns to reproduce that distribution from the same underlying board state.

02 / CHEAP

Then make that instinct cheap.

One measured Jev decision took 159 ms. One Echo call took 0.20 ms on the same machine.

That does not just make Jev’s behaviour faster.
It makes different computation practical.

04 / TEST

Then test it somewhere untouched.

Twenty held-out boards, seeds 100–119. Same boards for every player. A crash ends the game.

Search spends more compute than Echo alone, but still less wall-clock time than one Jev move.
05 / BUILD

The copy is small because the job is small.

Echo is not a general replacement for Jev. It is a 22,212-parameter convolutional network trained for this one decision surface.

01

Label

Jev sees the raw board and supplies its full distribution over available moves.

02

Distill

Echo learns those distributions from three 10×10 planes: body, head and food.

03

Follow the mistakes

Echo drives. Jev labels the states Echo actually reaches. Retrain twice.

The interesting question is not whether a tiny model can replace Jev.
It is what becomes possible when one narrow piece of Jev costs almost nothing.
