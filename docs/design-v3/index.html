06 · How Echo learned

Copy Jev. Then learn from Echo's mistakes.

Copying only the states Jev visits isn't enough: one wrong move can send Echo somewhere the training set never covered. So Echo drives, Jev labels the states Echo actually reaches, and Echo retrains.

01 · LABEL

Ask Jev

Collect Jev’s full move distribution on raw Snake boards.

02 · DISTILL

Train Echo

A tiny convolutional network learns to reproduce those distributions.

03 · RECOVER

Let Echo drive

Jev labels the states created by Echo’s own mistakes. Retrain twice.
