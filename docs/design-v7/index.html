06 / WHAT I HAD TO FIX

Three versions of the experiment were misleading.

01

The first Echo had an easier input.

It saw 28 features code had already computed. Jev had to read the board. I rebuilt Echo on the raw board.

02

Echo wandered off the training distribution.

Its own mistakes created unfamiliar states. I let Echo drive and Jev label wherever it ended up, then retrained twice.

03

Search accidentally knew where future food would spawn.

The simulator copied the game's RNG. I gave simulated futures fresh randomness and reran the result.

What else could you build if you could copy one narrow capability this cheaply?
