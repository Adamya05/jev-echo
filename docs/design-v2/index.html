The leverage

Same decision. Very different budget.

Jev is the stronger teacher. Echo is the cheap imitation. The point is not that Echo suddenly becomes smarter — it’s that you can ask it vastly more questions before the clock runs out.

How Echo exists

Turn Jev’s judgment into a tiny local policy.

Jev sees a text description of the board and returns a probability for each move. Echo sees the same state as three 10×10 grids and learns to match Jev’s full probability distribution.

Why search works

Cheap judgment becomes useful computation.

Snake is unusually friendly to this experiment: the rules can cheaply simulate the next state. Echo scores the branches; the tree discovers which apparently reasonable moves lead to death.

Usually 7–8 moves deep within the time budget

Echo supplies the prior.

When branches look equally good, the search naturally follows the policy Echo learned from Jev.

Simulation exposes consequences.

Moves that look plausible now but become fatal several steps later lose value.

The speed gap is the whole trick.

Search only helps because Echo can be queried hundreds of times cheaply.

Reproduce it

The experiment is small enough to inspect end to end.

The repo includes collection, training, DAgger, held-out evaluation, search, and the page build.

01 · Collect Jev labels14,391 initial boards

Run collect_raw.py to record board states and Jev’s full move distributions.

02 · Train the student22,212 parameters

train_board.py trains the small board network to match Jev’s distribution.

03 · DAgger twice23,808 more boards

Let Echo drive, ask Jev to label the states Echo actually visits, then retrain. Repeat once more.

04 · Race on untouched boardsboards 100–119

Compare Jev, Echo and Echo + search with crashes enabled. The README has the exact commands and seeds.

What this does not prove

Keep the claim narrow.

One tiny task.A 10×10 grid and four possible moves.
Search gets a simulator.Snake’s next state is cheap to predict. Most real tasks are not.
Twenty held-out boards.Useful evidence, not a giant benchmark.
Recorded on Apple M4.The page reports measured runs; nothing here is a live model call.
