How the values are calculated

Echo supplies move preferences. Search simulates every offered move and reweights each preference by exp(child value), then normalizes. The weighted average of the child values becomes the parent value. A death has value −(score + 10), here −30. A surviving leaf with no food gained has value 0. Approximately-zero parent values are shown as ≈0. Search weights are not probabilities of survival.
