Train your own

Here's the whole loop for Snake.

  1. Have Jev label your inputs.
    13,686 boards cost $0.27.

    uv run python collect_raw.py --games 90

  2. Train Echo to copy it.
    About 30 seconds on a laptop.

    uv run python train_board.py

  3. Race them.

    uv run python -m sysone.snake.compare --games 10 --max-steps 2000 \
    --configs jev_raw board_student board_budget_197

  4. Let Echo drive. Have Jev label the states Echo actually reaches, then retrain.
    Only needed with the safety net off. The README has the commands.

Snake makes looking ahead unusually cheap because the next board is exactly predictable. In other domains, the best use of the saved time will be different.
