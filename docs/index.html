Train your own

Here's how to do it for Snake. Your coding agent of choice will happily help you port it to anything else.

  1. Have Jev label your inputs. For Snake that was 13,686 boards, for $0.27.

    uv run python collect_raw.py --games 90

  2. Train a small network to copy it. About thirty seconds on a laptop.

    uv run python train_board.py

  3. Race them.

    uv run python -m sysone.snake.compare --games 10 --max-steps 2000 \
    --configs jev_raw board_student board_budget_197

For the version with the safety net off, run the same steps with SNAKE_ALLOW_CRASH=1 in front.

Search strategy depends heavily on the domain. Snake's rules predict the next board exactly, which is what makes thinking ahead cheap here.
