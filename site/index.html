Train your own

Here's how to do it for Snake. Your coding agent of choice will happily help you port it to anything else.

  1. Have Jev label your inputs. For Snake that was 14,391 boards, for $0.29.

    SNAKE_ALLOW_CRASH=1 uv run python collect_raw.py --games 90 \
    --out results/dataset_board_crash.npz

  2. Train a small network to copy it. About thirty seconds on a laptop.

    uv run python train_board.py --data results/dataset_board_crash.npz \
    --out results/student_board_crash.npz

  3. Race them.

    SNAKE_ALLOW_CRASH=1 uv run python -m sysone.snake.compare --games 10 \
    --max-steps 150 --configs jev_raw board_student board_budget_181

Search strategy depends heavily on the domain. Snake's rules predict the next board exactly, which is what makes thinking ahead cheap here.
